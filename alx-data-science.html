Overview

About the Programme

ALX Africa's Data Science programme is a competitive, portfolio-driven certification that trains participants through hands-on coding challenges, graded notebooks, and real-world datasets. The programme covers the full data science workflow from data ingestion and cleaning through exploratory analysis, statistical modelling, and machine learning.

The primary datasets used throughout the programme are drawn from the fictional Maji Ndogo region: a farm survey dataset covering agricultural conditions and yield across multiple provinces, and a water services dataset tracking infrastructure improvement costs and project progress. Both datasets reflect real data science challenges encountered in development and public sector contexts across Africa.

Maji Ndogo Agricultural Data Analysis
Graded Coding Challenge — Pandas and SQL
Core Project

What I built

A complete data analysis pipeline on the Maji Ndogo farm survey dataset, connecting to a SQLite database, joining four tables, cleaning the data, and implementing five graded analytical functions.

Tasks completed

  • Connected to SQLite database using SQLAlchemy and executed JOIN queries across geographic_features, weather_features, soil_and_crop_features, and farm_management_features tables using Field_ID
  • Cleaned data: fixed swapped column names, corrected spelling errors in crop type labels, converted negative elevation values to positive
  • Built explore_crop_distribution() — filters by crop type and returns mean Rainfall and mean Elevation as a tuple
  • Built analyse_soil_fertility() — groups by soil type and returns mean soil fertility for each type
  • Built climate_geography_influence() — groups by a given column and aggregates Elevation, Min temp, Max temp, and Rainfall
  • Built find_ideal_fields() — filters above-average yield fields, groups by crop type, and returns the top performing crop as a string
  • Built find_good_conditions() — multi-criteria filter combining yield threshold, temperature range (12 to 15°C), and pollution level below 0.0001
Farm Yield Prediction — Linear Regression Model
Machine Learning — Regression Analysis
ML Project

What I built

A linear regression model to predict farm yield (Standard_yield) from agricultural features, with full feature correlation analysis, model evaluation, and residual diagnostics.

Key findings

  • Soil Moisture was the strongest predictor of yield with a correlation of r = 0.855
  • Fertilizer Use showed moderate positive correlation (r = 0.303)
  • Temperature, Slope, and Pollution Level all showed negative relationships with yield
  • Residual analysis confirmed normally distributed errors and stable variance, validating the linear regression assumptions
  • Q-Q plot and scale-location diagnostics confirmed the model fit was sound
Maji Ndogo Water Services Cost Analysis
SQL and Pandas — Infrastructure Data
Data Analysis

What I built

An analysis of water infrastructure improvement costs across towns in the Maji Ndogo region, identifying which improvement types consumed the largest share of project budgets.

Tasks completed

  • Loaded and explored a multi-sheet Excel dataset covering project progress and cost data
  • Filtered data by town (Amanzi) and grouped by improvement type using pandas GroupBy
  • Aggregated total costs per improvement category (Drill well, RO filters, public taps, UV and RO filters)
  • Identified the highest-cost improvement type using idxmax() and sorted results
  • Applied boolean indexing and multi-condition filtering across the dataset
